## 이 앱

AI 타자연습 프로젝트(개인 과제). 제안서 11월 24일, 최종 발표 12월 8일. 기획 메모는 what_todo.txt.

- data/sentences/*.jsonl: 연습 문장. 한 줄에 문장 하나, 필드는 id, category, text 순서. tags는 저장하지 않는다.
- tag_rules.txt: 문장 특성 태그 규칙. 태그는 문장 내용에서 계산해 표시와 요약 참고에만 쓴다.
- tools/tag_sentences.py: 태그 규칙의 계산 여부를 확인한다. 태그를 파일에 저장하지 않는다.
- tools/check_sentences.py: id 연속성, 허용 문자, 우세 언어 길이 상한(한국어 우세 100자, 영어 우세 150자)을 검사한다.
- tools/summary.py: 문장 특성 통계와 히스토그램을 출력한다.
- 문장 파일은 JSON 배열이 아니라 한 줄에 객체 하나인 형식(jsonl)을 유지한다. 태그는 파일에 기록하지 않는다.
- 기준값을 바꿀 때는 tag_rules.txt와 tools/tag_sentences.py를 함께 고친다.
- 라운드: 문장 1개를 입력하면 한 라운드가 끝나고 다음 라운드로 넘어간다(문장 수 = 라운드 수). 기본 30라운드.
- tools/make_round.py: 문장 30개(중복 없음)를 뽑는다. 30개의 총 글자 수는 (전체 문장 평균 길이 x 30)의 ±30% 안이어야 하고, 벗어나면 전체를 다시 뽑는다. 나중에는 AI가 사용자에게 맞춰 문장을 생성해 라운드를 짤 예정이며, 이 도구는 임시용이다.
- 사용자 지시: PPT와 제안서는 건드리지 않는다. 할 일은 프로그램 제작뿐이다.

### 타자 연습 화면 (웹, 브라우저에서 실행)
- 시작 화면: 키보드 종류(데스크톱/노트북), 다음 키 표시 여부 선택, 30라운드 시작, 지난 기록 목록.
- 연습 화면: 위 칸에 칠 문장, 아래 칸에 내가 친 글자(두벌식 입력을 조합해 보여 줌). 다 맞게 치면 Enter를 눌러야 다음 라운드로 넘어가고 자동으로 넘어가지 않는다. 오타는 Backspace로 지워야 진행된다.
- 판정은 키 위치(event.code)와 한/영 입력 상태를 함께 본다. 한글 자모 키는 IME가 켜져 있어야(keydown의 key가 Process) 맞고, 영문 글자 키는 꺼져 있어야 맞다. 어긋나면 오입력 종류 "한/영 상태"로 기록한다. 숫자·기호·스페이스는 한/영과 무관. IME 감지를 위해 화면에 보이지 않는 입력창에 포커스를 둔다.
- 기록: 키마다 시각, 누른 키, 눌러야 할 키, 오입력 종류, 눌러야 할 키와의 거리·방향. 브라우저 저장소에 최근 8회까지 보관.
- 결과 화면: 약점 요약(규칙 기반 문장), 라운드별 속도, 키보드 오타율·느린 키 지도, 자주 틀린 키, 오입력 종류, 문장 특성(tags)별 속도, 느린 어절, AI에 보낼 요약 데이터.
- 문장은 data/sentences/*.jsonl을 그대로 읽는다. 문장을 추가한 뒤 tools/tag_sentences.py와 check_sentences.py를 실행한다.
- 라운드 구성(src/lib/sentences.ts)은 make_round.py와 같은 규칙(총 글자 수 ±30%, 아니면 다시 뽑기)이다.
- AI 코치(결과 화면): 요약 데이터를 선택한 AI 제공자에 보내 피드백(총평, 잘한 점, 약점 최대 3개, 다음 연습)을 받는다. 피드백은 기록과 함께 저장된다.
- 약점 연습: AI가 약점에 맞춰 문장 10개를 만든다. 문자 규칙·길이 상한·총 글자 수 ±30% 검사에 실패하면 서버가 다시 만들게 한다(최대 3번). tags는 문장 내용으로 계산해 화면과 요약에만 쓰고 저장하지 않는다.
- AI 호출 코드는 server/ai.ts, 규칙은 shared/rules.ts(파이썬 태그 규칙과 같은 결과인지 확인함). 개발 서버가 /api/feedback, /api/practice로 중계한다.
- Gemini는 GEMINI_API_KEY 환경 변수 또는 앱 설정 키를 사용하고 gemini-3.5-flash-lite/gemini-3.8-flash를 제공한다. Multi AI는 OpenAI 호환 Baze 게이트웨이를 사용하며 선택 모델과 키를 Windows 계정 암호화 저장소에 보관한다.
- 아직 없음: 코딩 카테고리, 손 중심점 사용자 입력. 노트북/데스크톱은 기록만 하고 배열 모양은 같다.
